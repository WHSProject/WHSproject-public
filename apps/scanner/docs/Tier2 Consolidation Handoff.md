## 검증 출처

139건 실험과 Scanner 75 suites / 1,276 tests는 고정 통합 후보 `2cdb3bb7305da198044b65c310b32fecd9030c81`에서 수행했다. 이번 정리는 그 커밋 전체를 #417 브랜치에 통합하고 기존 결과 문서 및 #404 문서를 추가한 것이다.

통합 직후 아래 실행 코드·테스트·설정의 diff가 비어 있음을 확인했다. 이번 정리에서 새 복원 알고리즘, 게이트 또는 Policy 조건은 추가하지 않았다.

```sh
git diff 2cdb3bb7305da198044b65c310b32fecd9030c81 HEAD -- apps/scanner/src apps/scanner/test apps/scanner/scripts apps/scanner/package.json pnpm-lock.yaml
```

dev 기준 PR 차이는 Scanner 하위 파일만 포함한다. 검증 후보에 이미 포함됐던 dev의 Dashboard/CI 이력은 새 PR 변경이 아니다. 전체 테스트와 139건 실험을 이번 정리를 위해 다시 실행하지 않았으며 이전 검증과 현재 코드 동일성 확인을 구분한다.

주요 결과: 139/139 분석 완료, 기존 악성 입력 후보 추가 이탈 0, 정상 입력 후보 13→15. 생성된 6개 입력의 동일 실행 전후 JSON 합계 59.3% 감소, 코드 본문 146,638 bytes 동일. 이는 일반 탐지 성능 향상이나 실제 LLM 비용 절감률의 증명이 아니다. 자세한 수치·실패 이력은 Tier3 Input Capability Projection.md에 보존한다.
