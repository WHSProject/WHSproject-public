# 요구사항 정의서

## 프로젝트 목표

- 이 프로젝트가 해결하려는 문제를 작성합니다.
- 최종 사용자가 얻는 가치를 작성합니다.

## 핵심 기능

| 번호 | 기능 | 설명 | 담당자 | 상태 |
|---|---|---|---|---|
| 1 | 예: 로그인 | 사용자가 계정으로 로그인한다 | 미정 | 예정 |
| 2 | 예: 회원가입 | 사용자가 새 계정을 만든다 | 미정 | 예정 |

## 우선순위

- `P0`: 반드시 구현
- `P1`: 가능하면 구현
- `P2`: 시간이 남으면 구현

## 완료 기준

- 기능이 정상 동작한다.
- 에러 상황이 처리된다.
- 관련 문서가 업데이트된다.
- Pull Request 리뷰가 끝났다.
